## Method and interpretation

An HTTP GET sweep followed redirects for every distinct URL in all fields of the 25 tool records and sources of their 38 capability definitions. The sweep used a browser-style user agent, a 25-second timeout and a static-HTML fragment check. It recorded final destinations and page titles. Selected disputed sources were also opened with a web reader.

This file records **reachability, not a relevance/pass verdict**. HTTP 200 does not demonstrate that the page supports an authored claim, that a procedure works, or that rendered/authenticated content was read. Content review and correction recommendations are in the main assessment. Empty notes mean no additional exception is recorded here, not that the source was exhaustively content-validated.

No authored fragment failed the static check; this does not validate client-rendered anchors. Redirects are shown only when the final destination differs.
