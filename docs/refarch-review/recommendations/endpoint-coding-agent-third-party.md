# Review: Third-party coding & desktop agents

Files reviewed: `data/reference/architectures/endpoint-coding-agent-third-party.yaml` and its paired guidance.

## Overall assessment

The component inventory is strong, but the normal model path and the control loci are not yet internally coherent. The file also carries several stale statements from the prior zone grammar. Resolve the high-priority defects before treating this as a target-state reference.

## Preserve

- Keep the separate local, enterprise, and external tool-service tiers; that distinction is useful and conforms to the shared pattern.
- Keep the vendor control plane opaque as one block and retain the explicit remote-steering scenario after correcting its path.
- Keep prompt injection on repository/document ingress, tool-registry tampering, memory poisoning, and shadow-agent discovery as first-class concerns.
