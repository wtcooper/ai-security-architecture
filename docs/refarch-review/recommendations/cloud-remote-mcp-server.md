# Review: Remote MCP server you publish

Files reviewed: `data/reference/architectures/cloud-remote-mcp-server.yaml` and its paired guidance.

## Overall assessment

The protocol update is current and the publisher-side inversion is well framed. The primary corrections are ownership of callers, OAuth flow accuracy, and replacing the “Tool definitions” artifact masquerading as a running service.

## Preserve

- Keep the current 2026-07-28 stateless POST transport, mirrored-header validation, and backward-compatibility awareness.
- Keep explicit tenant checks in application code and the prohibition on forwarding caller tokens upstream.
- Keep tool descriptions/schemas as security-relevant versioned content after representing their real storage/publishing tier.
  - Second review: The qualifier "after representing their real storage/publishing tier" presumes MCP-04, which this review disagrees with — the `Tool definitions` block already is that store, registered in the vocabulary and defended by a recorded deviation. Keep the content unconditionally.
