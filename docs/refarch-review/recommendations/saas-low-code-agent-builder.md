# Review: UI/low-code managed agent runtime

Files reviewed: `data/reference/architectures/saas-low-code-agent-builder.yaml` and its paired guidance.

## Overall assessment

Population governance and maker-credential inheritance are the right differentiators. The graph breaks its own vendor-opacity rule by drawing the vendor’s model-provider internals, and its on-premises path bypasses the customer authorization gateway without equivalent controls.

## Preserve

- Keep vendor internals as one opaque platform block.
- Keep citizen builder and consumers as distinct actors.
- Keep maker-versus-invoker credentials, population inventory, connector classification, retrieval poisoning, and author-departure lifecycle as core concerns.
