# Review: Self-hosted model inference

> **Status (2026-09-01): APPLIED** on branch `refarch-review-updates`. Every finding was
> executed per its Second-review verdict — Agree rows as written, Modify rows as amended,
> Disagree rows via the stated alternative — with guidance updated in the same commits.


Files reviewed: `data/reference/architectures/cloud-self-hosted-inference.yaml` and its paired guidance.

## Overall assessment

The shared-serving and cache-isolation analysis is valuable. The artifact flow is backwards: the untrusted runtime fetches source weights and is also credited with scanning/promotion, so the target has no independent supply-chain gate.

## Preserve

- Keep API, runtime, storage, and source as separate concepts after fixing direction and promotion.
- Keep cache/co-tenancy, finite-capacity, serving-stack vulnerability, model theft, and deployment-tampering concerns.
- Keep gateway-fronted admission and per-tenant cache/quotas as target-state requirements.
