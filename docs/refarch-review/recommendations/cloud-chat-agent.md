# Review: Chat agent with tools

Files reviewed: `data/reference/architectures/cloud-chat-agent.yaml` and its paired guidance.

## Overall assessment

The delegated-user authority model is useful, but the drawing treats human approval as an inherent property of chat when most tool-calling loops execute tools mid-turn. The target can require approval, but its sequence must actually show it.

## Preserve

- Keep the workload identity separate from the user’s delegated grant.
- Keep conversation state and retrieval index distinct, with hard user/session boundaries.
- Keep output encoding at the rendering edge and approval wording specific enough to review.
