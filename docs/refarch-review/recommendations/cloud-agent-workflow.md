# Review: Multi-agent workflow

Files reviewed: `data/reference/architectures/cloud-agent-workflow.yaml` and its paired guidance.

## Overall assessment

Durability, replay, and delegation are correctly identified as the differentiators. The identity model is currently impossible as drawn: subagents are objects in one process but are also claimed to have separately revocable workload identities.

## Preserve

- Keep supervisor/subagent nesting if the selected deployment model is one runtime.
- Keep durable journal, replay, narrowed delegation, and inter-agent output-as-input as the differentiators.
- Keep sandboxed generated-code execution outside the orchestration tier.
