# Archived: the zone-style reference architectures

This directory holds the first-generation reference architecture catalogue — 28 archetypes
drawn as vertical trust-boundary zone diagrams over the node/zone/control-kind vocabulary in
`vocabulary.yaml`. It was superseded in August 2026 by the flow-style architectures in
`data/reference/architectures/`, which follow the F5 AI reference architecture grammar:
capability blocks connected by typed data paths, with risks and capabilities pinned onto the
diagram and keyed to a side rail.

Nothing here is loaded by the build. The content — archetype boundaries, exemplars, sources,
risk and capability mappings, and the per-crossing control analysis — remains the research
base the flow-style rebuild draws from, one archetype at a time. The renderer that drew these
lives at git tag/history `Zone-style reference architectures` (see the commit of the same name).
